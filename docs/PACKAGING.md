# Сборка и публикация мода

## Артефакт

В релиз входит один файл:

`liminal-industries-russian-translation-1.19.3-7-ae2-fix.jar`

JAR содержит языковые ресурсы и переведённую книгу квестов. Для одиночной игры
его устанавливают в каталог `mods` профиля. Для выделенного сервера тот же JAR
устанавливают на сервер и клиент.

`1.19.3-7 (AE2 fix)` — версия модпака. Он работает на Minecraft `1.20.1`.

## Структура исходников

```text
src/
├── quests/
│   ├── data.snbt
│   ├── chapter_groups.snbt
│   └── chapters/
│       └── *.snbt
└── resourcepack/
    ├── pack.mcmeta
    └── assets/
        └── MOD_ID/
            └── lang/
                └── ru_ru.json
```

В `src/quests` хранится полное содержимое `config/ftbquests/quests`. Не
добавляйте туда прогресс игроков, миры, журналы и настройки сервера.

В `src/resourcepack` хранятся языковые ресурсы, которые Gradle включает в JAR.
Этот каталог не публикуется как отдельный устанавливаемый пакет.

Как обновлять перевод для новой версии модпака, описано в
[`UPDATING.md`](UPDATING.md).

## Сборка

Требуется JDK 17. Из корня репозитория запустите:

```sh
cd mod
./gradlew clean test build
```

Gradle берёт языковые файлы из `src/resourcepack`, квесты из `src/quests` и
создаёт `translatedFiles` в manifest по их актуальным SHA-256. Готовый JAR
создаётся в `mod/build/libs`.

## Проверка релиза

Перед выпуском:

1. Сверьте `modpack_version` в `mod/gradle.properties` с поддерживаемой версией
   в `README.md`.
2. Выполните `cd mod && ./gradlew clean test build`.
3. Проверьте имя JAR и версию в `META-INF/mods.toml`.
4. Установите JAR в чистый клиент и проверьте названия предметов и все главы
   квестов.
5. Установите тот же JAR на тестовый сервер и клиент.
6. Обновите копию старого мира и проверьте сохранность прогресса.
7. Убедитесь, что в Git нет JAR-файлов, журналов, миров, настроек сервера и
   архивов модпака.
8. Получите разрешение на публикацию перевода квестов. Не распространяйте
   чужой текст под своей лицензией без согласия автора.

## Публикация

При публикации на GitHub:

1. Создайте тег, например `v1.19.3-7-ae2-fix.1`.
2. Подготовьте описание изменений и добавьте результаты проверки в игре.
3. Приложите только собранный JAR.
4. Перечислите изменения и известные проблемы.

Тексты и имя файла для CurseForge хранятся в
[`CURSEFORGE.md`](CURSEFORGE.md).
