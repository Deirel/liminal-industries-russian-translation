# Перевод названий предметов

Полная актуальная методика находится в `TRANSLATION_METHODOLOGY.md`. Этот
документ служит краткой памяткой по названиям предметов.

Русские названия хранятся в version-specific payload. Одно и то же
каноническое дерево включается в клиентский мод выбранной версии и разбивается
на независимые ZIP-паки по `resource-packs.json`.

Английские `displayName` в KubeJS и исходные языковые файлы модов не
изменяются. Пак содержит только точечные `ru_ru`-переопределения.

## Источники

1. Эффективное английское имя после переопределений сборки.
2. Официальный русский перевод Minecraft 1.20.1.
3. Установленный `ru_ru` конкретной версии мода.
4. Редакторский перевод для KubeJS и отсутствующих строк.

Переводятся все предметы из фактического реестра сборки, если их рабочее
русское название отсутствует или осталось английским. Реестр берётся из
сгенерированного ProbeJS-типа `Item`, поэтому охватывает и предметы, которые
не встречаются в квестах.

## Каталог

Команды выполняются из корня репозитория перевода. Каталог модпака задаётся
отдельно:

```sh
TRANSLATION_REPO="$HOME/Documents/minecraft-industrial-backrooms"
MODPACK_ROOT="$HOME/Projects/minecraft-industrial-backrooms"
cd "$TRANSLATION_REPO"
```

Собрать полный каталог зарегистрированных предметов:

```sh
python3 scripts/extract_item_names.py \
  --root "$MODPACK_ROOT" \
  --resource-pack translation-versions/1.19.3-7-ae2-fix/payload/resourcepack \
  --scope all \
  --output item-translation-work/all_items.tsv
```

Для отдельной проверки предметов из квестов:

```sh
python3 scripts/extract_item_names.py \
  --root "$MODPACK_ROOT" \
  --resource-pack translation-versions/1.19.3-7-ae2-fix/payload/resourcepack \
  --scope quest \
  --output item-translation-work/quest_items.tsv
```

Результат записывается в `item-translation-work/quest_items.tsv`.

Статусы:

- `HAS_RU` — в установленной сборке есть русская строка;
- `MISSING_RU` — требуется переопределение;
- `RU_EQUALS_EN` — русская строка намеренно или ошибочно оставлена английской
  и требует редакторского решения.

Текущий полный каталог содержит 9 322 предмета. Пропусков русского названия
нет; без перевода намеренно оставлены только собственные имена `Ars Ecclesia`,
`"Enderios"`, `Snad` и `Suol Snad`.

Пересобрать ресурс-пак из всех проверенных каталогов
`item-translation-work/*_names_ru.tsv`:

```sh
python3 scripts/build_item_language_pack.py
```

Файлы `ru_ru.json` будут записаны по пространствам имён в payload Rescripted.
Для обычного version flow используйте `build_version_resources.py`, который
строит payload из манифеста и глобального каталога.

## Правила стиля

- Название должно быть коротким и естественным для игрового интерфейса.
- Используется официальная терминология Minecraft: `редстоун`, `скалк`,
  `Незер`, `Энд`.
- Бренды и технические сокращения не переводятся: `Create`, `AE2`, `ME`,
  `P2P`, `FE`.
- Все варианты одного семейства используют одинаковое базовое имя.
- Состояние по возможности выражается прилагательным:
  `Активный контроллер`, `Пустая ячейка`, `Повреждённая лампа`.
- Перевод квестов и `QUEST_GLOSSARY.*` должен точно совпадать с итоговым
  названием предмета.

## Проверка

1. Проверить корректность всех JSON-файлов.
2. Повторно собрать полный каталог и убедиться, что пропуски закрыты.
3. Собрать клиентский мод с обновлённым payload выбранной версии.
4. Выполнить `verifyResourcePackPartition` и убедиться, что все ключи
   распределены ровно один раз.
5. Проверить предметы в JEI и награды FTB Quests при языке `ru_ru`.
6. Выполнить поиск оставшихся английских названий и редакторскую проверку.
