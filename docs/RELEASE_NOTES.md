# Русский перевод для 1.19.3 - 7 (AE2 fix)

Русский перевод квестов и названий предметов для
[Liminal Industries - Rescripted](https://www.curseforge.com/minecraft/modpacks/liminal-industries-rescripted).

## Совместимость

- Liminal Industries - Rescripted `1.19.3 - 7 (AE2 fix)`
- Minecraft `1.20.1`
- Forge `47.4.13`
- FTB Quests `2001.4.22`

## Файлы

- `liminal-industries-russian-translation-1.19.3-7-ae2-fix.jar` — Forge-мод
  с переводом названий и безопасной установкой книги квестов
- `liminal-industries-russian-resource-pack-1.19.3-7-ae2-fix.zip` — перевод
  названий предметов для ручной установки
- `liminal-industries-russian-quest-configs-1.19.3-7-ae2-fix.zip` — перевод
  книги квестов для ручной установки
- `SHA256SUMS` — контрольные суммы архивов

Для установки модом поместите JAR в `mods`; на выделенном сервере установите его
и на сервер, и на клиенты. Для ручной установки в одиночной игре нужны оба
ZIP-файла. На выделенном сервере конфиги квестов ставит администратор, а каждый
игрок отдельно устанавливает ресурс-пак.

Перед установкой остановите игру или сервер. Сделайте копию мира и
`config/ftbquests/quests`. Полная инструкция — в `README.md`.
