```markdown
# Liminal Industries: Russian Translation

An unofficial Russian translation for Liminal Industries - Rescripted.

This resource pack translates selected item names into Russian.

## Compatibility

The latest supported version of Liminal Industries - Rescripted is **1.19.3 - 7 (AE2 fix)**.

- Minecraft 1.20.1
- Forge 47.4.13

## Installation

1. Download the resource pack.
2. Place the ZIP file in the `resourcepacks` folder of the modpack profile. Do not extract it.
3. Start the game and select Russian.
4. Enable the resource pack in the Resource Packs menu.

Quest translations are distributed separately because FTB Quests configuration files cannot be installed through a resource pack.

Source code, quest translations, checksums, and detailed installation instructions are available on GitHub:

https://github.com/Deirel/liminal-industries-russian-translation
```

```markdown
# Liminal Industries: Russian Quest Translation

An unofficial Russian quest translation for Liminal Industries - Rescripted.

This package replaces the FTB Quests configuration files with their Russian translations. It does not include the resource pack for translated item names.

## Compatibility

The latest supported version of Liminal Industries - Rescripted is **1.19.3 - 7 (AE2 fix)**.

- Minecraft 1.20.1
- Forge 47.4.13
- FTB Quests 2001.4.22

## Single-player installation

1. Stop the game.
2. Back up `config/ftbquests/quests`.
3. Extract the archive into the root directory of the modpack profile.
4. Confirm file replacement.
5. Start the game and select Russian.

## Dedicated server installation

1. Stop the server.
2. Back up the world and `config/ftbquests/quests`.
3. Extract the archive into the server root directory.
4. Confirm file replacement and start the server.

Players on a dedicated server receive the translated quests from the server. Each player must install the separate resource pack to translate item names.

Source code, the resource pack, checksums, and detailed installation instructions are available on GitHub:

https://github.com/Deirel/liminal-industries-russian-translation
```
