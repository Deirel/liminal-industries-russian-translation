# Liminal Industries Russian Translation Mod

Forge-мод с русским переводом для модпака
Liminal Industries - Rescripted.

Целевая версия:

- Minecraft `1.20.1`;
- Forge `47.4.13`;
- Liminal Industries - Rescripted `1.19.3 - 7 (AE2 fix)`;
- FTB Quests `2001.4.22`;
- Java `17`.

Мод устанавливается в профиль CurseForge одним JAR-файлом. Переводы названий
загружаются как обычные ресурсы Forge. Текст FTB Quests подменяется на клиенте
только во время отображения и никогда не записывается в каталог конфигурации.

## Установка

1. Соберите мод командой `./gradlew clean test build` или возьмите готовый JAR.
2. Поместите
   `liminal-industries-russian-translation-1.19.3-7-ae2-fix.jar` в каталог
   `mods` профиля.
3. Выберите русский язык в настройках Minecraft.

На выделенный сервер мод устанавливать не нужно. Для русского интерфейса каждый
игрок ставит JAR на свой клиент. Перед показом перевода мод сверяет полный набор
ID объектов книги. Если книга не соответствует поддерживаемой версии, остаётся
оригинальный текст и в журнал записывается предупреждение.

При другом выбранном языке и после удаления мода оригинальный текст отображается
автоматически: на диске ничего не заменяется и резервные копии не создаются.

## Сборка и проверка

Требуется JDK 17. Из каталога `mod/` команда `./gradlew clean test build`
проверяет встроенный перевод квестов, индекс SNBT-файлов и все `ru_ru.json`.
Готовый файл создаётся в `mod/build/libs`.

Сборка напрямую подключает `../src/resourcepack` и `../src/quests`. Индекс
встроенных SNBT-файлов генерируется автоматически, поэтому перевод не
дублируется в `mod/src/main/resources`.

Полное техническое задание и ограничения первой версии описаны в
[`TECHNICAL_SPEC.md`](TECHNICAL_SPEC.md).
