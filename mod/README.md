# Liminal Industries Russian Translation Mod

Forge-мод с русским переводом для модпака
Liminal Industries - Rescripted.

Целевая версия:

- Minecraft `1.20.1`;
- Forge `47.4.13`;
- Liminal Industries - Rescripted `1.19.3 - 7 (AE2 fix)`;
- FTB Quests `2001.4.22`;
- Java `17`.

Мод устанавливается в профиль CurseForge одним JAR-файлом. Переводы
названий загружаются как обычные ресурсы Forge. Переведённая книга FTB Quests
устанавливается только поверх проверенной версии оригинальной книги; неизвестные
файлы мод не изменяет.

## Установка

1. Соберите мод командой `./gradlew clean test build` или возьмите готовый JAR.
2. Поместите `liminal-industries-russian-translation-1.0.0.jar` в каталог
   `mods` профиля.
3. Для перевода книги на выделенном сервере установите тот же JAR на сервер.
4. Выберите русский язык в настройках Minecraft.

При первом совместимом запуске исходная книга перемещается в
`config/liminal_industries_ru/backups/<UTC_TIMESTAMP>/quests`, а перевод
устанавливается в `config/ftbquests/quests`. Повторный запуск ничего не
перезаписывает. Если набор или содержимое файлов отличаются от проверенного
оригинала, мод только записывает отказ в `logs/latest.log`.

После аварийного завершения между перемещениями книгу можно вручную восстановить
из последнего backup при остановленной игре.

## Сборка и проверка

Требуется JDK 17. Из каталога `mod/` команда `./gradlew clean test build`
проверяет файловый установщик, сгенерированный manifest, контрольные суммы SNBT
и все `ru_ru.json`. Готовый файл создаётся в `mod/build/libs`.

Сборка напрямую подключает `../src/resourcepack` и `../src/quests`. Manifest с
хешами переведённых квестов генерируется автоматически, поэтому перевод не
дублируется в `mod/src/main/resources`.

Полное техническое задание и ограничения первой версии описаны в
[`TECHNICAL_SPEC.md`](TECHNICAL_SPEC.md).
