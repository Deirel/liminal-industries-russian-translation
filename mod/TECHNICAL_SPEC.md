# Техническая спецификация

## Назначение

Мод добавляет русский перевод названий предметов и текста FTB Quests для
Liminal Industries `1.19.3`.

Целевое окружение:

- Minecraft `1.20.1`;
- Forge `47.4.13`;
- FTB Quests `2001.4.13`;
- Java `17`.

Это клиентский мод. Он работает в одиночной игре и при подключении к серверу,
на котором мод не установлен.

## Архитектура

Языковые файлы из `src/resourcepack` включаются в JAR как обычные ресурсы Forge.
Переведённые SNBT-файлы из `src/quests` включаются в JAR как неизменяемые
ресурсы. Gradle создаёт для них индекс
`liminal_industries_ru/quest-files.list`.

При первом запросе текста квеста клиент:

1. читает индекс и SNBT только из classpath JAR;
2. собирает переводы `title`, `subtitle` и `description` по ID объектов;
3. сравнивает точный набор ID встроенной книги с набором ID книги,
   синхронизированной FTB Quests;
4. подставляет русский текст только при полном совпадении и выбранном языке
   `ru_ru`.

Mixin-инъекции перехватывают возвращаемые значения:

- `QuestObjectBase#getTitle`;
- `Quest#getSubtitle`;
- `Quest#getDescription`.

Оригинальные объекты FTB Quests и их сериализованные данные не изменяются.
При другом языке, несовместимой книге или отсутствии перевода возвращается
оригинальное значение.

## Работа с файлами

Производственный код не читает и не записывает каталог игры. В частности, мод:

- не заменяет файлы FTB Quests;
- не создаёт резервные копии;
- не устанавливает resource pack;
- не хранит состояние между запусками.

Поэтому удаление JAR полностью отключает перевод и сразу возвращает оригинальное
отображение.

## Совместимость

Зависимость от FTB Quests обязательна только на клиенте и зафиксирована на
версии `2001.4.13`. Полное равенство набора ID защищает от применения текста к
другой версии книги. Несовпадение фиксируется предупреждением в журнале, но не
мешает запуску игры.

## Сборка и тесты

Команда:

```sh
cd mod
./gradlew clean test build
```

Тесты проверяют:

- корректность и отсутствие дубликатов в `ru_ru.json`;
- чтение всех встроенных SNBT-файлов;
- ожидаемый набор ID и контрольные фрагменты перевода;
- строгую проверку совместимости книги.

Готовый JAR создаётся в `mod/build/libs`.
