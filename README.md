# Русский перевод Liminal Industries - Rescripted

Перевод квестов и названий предметов для модпака
[Liminal Industries - Rescripted](https://www.curseforge.com/minecraft/modpacks/liminal-industries-rescripted).

Перевод сделан для:

- Liminal Industries - Rescripted `1.19.3 - 7 (AE2 fix)`
- Minecraft `1.20.1`
- Forge `47.4.13`
- FTB Quests `2001.4.22`

Скачать архивы можно на странице
[последнего релиза](../../releases/latest). Часть `1.19.3-7-ae2-fix` в имени
архива — это версия модпака, а не Minecraft.

## Установка

Перед установкой остановите игру или сервер. Сделайте бэкап мира (если есть) и папки `config/ftbquests/quests`.

### Клиент

Для одиночной игры:

1. Скачайте архив
   `liminal-industries-russian-client-1.19.3-7-ae2-fix.zip`.
2. Распакуйте его в корень профиля с модпаком. Если лаунчер спросит о замене
   файлов, подтвердите её.
3. Запустите игру и выберите русский язык.
4. Включите `liminal-industries-russian-resources.zip` в меню наборов ресурсов.
   Поставьте его выше других наборов, меняющих названия предметов.

После распаковки должны появиться:

```text
config/ftbquests/quests/
resourcepacks/liminal-industries-russian-resources.zip
```

### Сервер + клиент

Для игры на выделенном сервере нужны **оба** пакета:

1. Администратор распаковывает
   `liminal-industries-russian-server-1.19.3-7-ae2-fix.zip` в корень сервера.
2. Каждый игрок распаковывает клиентский архив в корень своего игрового
   профиля и включает ресурс-пак, как описано выше.
3. Запустите сервер и проверьте, нет ли ошибок FTB Quests в журнале.

Одного клиентского пакета недостаточно. FTB Quests загружает квесты с сервера,
а не из файлов клиента. Без серверного пакета переведутся названия предметов,
но не квесты.
