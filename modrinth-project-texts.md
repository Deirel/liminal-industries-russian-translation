# Описание

# Liminal Industries: Russian Translation

An unofficial Russian translation for:

- [Liminal Industries](https://www.curseforge.com/minecraft/modpacks/liminal-industries) **1.19.3 (Original)** (CurseForge)
- [Liminal Industries - Rescripted](https://www.curseforge.com/minecraft/modpacks/liminal-industries-rescripted) **1.19.3 - 7 (AE2 fix)** (CurseForge)

The mod translates:

- FTB Quests titles, subtitles, and descriptions
- Item and block names from the modpack

Quest translations are applied **client-side and in memory only**. The mod does not replace or modify FTB Quests configuration files, create backups, or change quest progress. Removing the mod restores the original text.

## Compatibility

Supported modpacks:

- Liminal Industries **1.19.3 (Original)** with FTB Quests **2001.4.13**
- Liminal Industries - Rescripted **1.19.3 - 7 (AE2 fix)** with FTB Quests **2001.4.22**

Shared requirements:

- Minecraft **1.20.1**
- Forge **47.4.13**

Each release is built for one exact quest book. Use the JAR that matches the installed modpack edition. Unsupported quest books retain their original text.

## Installation

1. Download the JAR that matches the installed modpack edition.
2. Place the mod JAR in the client profile's `mods` folder.
3. Select Russian in Minecraft's language settings.
<p/>

The mod is not required on dedicated servers. Each player who wants the translation installs it on their own client.

No separate resource pack or manually installed quest configuration is required.
