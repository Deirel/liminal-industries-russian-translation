Очиститель
Смешивание жидкостей!
<&multiblock>Очиститель — сложный мультиблок, который перерабатывает одну или две жидкости в другую. Чаще всего его используют для производства биодизеля.
Чтобы сформировать конструкцию, нажмите ПКМ по тяжёлому инженерному блоку в среднем слое.
Жидкости вводятся через два порта по обе стороны блока и выводятся через порт, отмеченный оранжевым цветом, на передней стороне. Также возможно использование ведер для взаимодействия с резервуарами нефтеперерабатывающего завода.
Подача сигнала красного камня на панель управления спереди остановит процесс работы машины. Это поведение можно изменить с помощью отвертки инженера.
<&diesel>Большинство процессов нефтепереработки требуют добавления катализатора для обеспечения реакции. Этот катализатор не расходуется, но без него процесс не пойдет.
