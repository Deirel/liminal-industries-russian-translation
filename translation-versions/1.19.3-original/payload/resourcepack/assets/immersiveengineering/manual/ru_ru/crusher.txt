Дробилка
Держите руки подальше!
Дробление руды эффективно повышает выход: из каждой единицы руды получается две порции пыли для последующей плавки. Эта промышленная дробилка делает всё быстро, а скорость обработки зависит от подаваемой мощности.
Подача сигнала красного камня на панель управления спереди остановит процесс дробления. Это поведение можно изменить с помощью отвертки инженера.
Конструкция формируется ПКМ молотом инженера по центральному блоку спереди. Передняя часть — широкая сторона конструкции с лёгким инженерным блоком внизу.
Дробилка подходит не только для руды. Любое упавшее внутрь живое существо получит огромный урон, а машина выдаст соответствующую добычу. Предметы, которые нельзя обработать, будут уничтожены.
