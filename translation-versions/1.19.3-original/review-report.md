# Редакторская проверка дельты

Проверены все новые записи версии:

- 53 строки квестов;
- 425 названий предметов;
- соответствие `id + source_hash` манифесту;
- сохранность кодов форматирования, подстановок и `{image:...}`;
- единообразие названий с `QUEST_GLOSSARY.tsv`;
- отсутствие пустых переводов и редакторских заглушек.

Во время проверки исправлены:

- `Petal Apothecary`: «Лепестковый алтарь» заменён на утверждённую
  «Лепестковую чашу»;
- три оставшиеся заглушки Create Crafts & Additions;
- число уровней у обрамлённого спрессовывающего полуящика;
- `Cardboard`: «Фанера» заменена на «Картон»;
- динамические translation key и английские имена предметов Thermal,
  встречающихся в квестах.

После правок операция утверждения добавляет только новые записи, повторный
запуск идемпотентен. Старые варианты глобального каталога не изменены.

162 записи оригинальной версии:

- 133 отображаемых имени блока;

извлечение манифеста даёт нулевую дельту, а итоговый payload содержит 2 652
языковых ключа, 455 строк квестов и 50 строк Patchouli.
