# Runtime-аудит названий предметов

`audit-mod` — отдельный служебный Forge-мод. Его классы и зависимость от JEI
не входят в публикуемый JAR перевода.

## Сборка

```sh
./mod/gradlew -p audit-mod clean test build \
  -PtranslationVersion=1.19.3-original

./mod/gradlew -p audit-mod clean test build \
  -PtranslationVersion=1.19.3-7-ae2-fix
```

Gradle выбирает версию обязательного translation-мода из общего
`translation-versions/<version>/build-config.json`. Результат:

```text
audit-mod/build/libs/liminal-industries-russian-translation-audit-<version>.jar
```

## Проверка в игре

1. Установить релизный JAR перевода и JAR аудита в реальный клиентский профиль
   соответствующего модпака.
2. Запустить игру, выбрать `Русский (Россия)` и войти в мир.
3. Дождаться полной загрузки JEI.
4. Выполнить клиентскую команду `/liminal_ru_audit`.
5. Проверить итог `PASS` и отчёт:

```text
liminal-industries-ru-audit/item-name-audit.json
```

Аудит объединяет все варианты `ItemStack`, фактически зарегистрированные в
JEI, с базовыми стеками всего runtime-реестра Minecraft. Для отображаемого
компонента имени проверяются только translation keys, которые действительно
использует выбранный русский шаблон. Неиспользуемые аргументы компонента не
влияют на результат. Ключ считается русским, если он присутствует в реально
загруженном `ru_ru.json` либо его runtime-значение отличается от английского:
это учитывает переводы, которые моды создают программно или передают как
fallback самого компонента. Нейтральные шаблоны вроде `%1$s-%2$s` не требуют
отдельного русского ключа. Английский fallback с обычным текстом по-прежнему
не засчитывается.

`FAIL` вызывают:

- отсутствующий русский translation key;
- пустое имя или исключение при его получении;
- буквальное имя без translation key и без кириллицы, которое нельзя
  автоматически подтвердить как русское.

Совпадения русского и английского значений записываются в
`same_as_english_keys` для редакторской проверки, но сами по себе не вызывают
`FAIL`: названия модов, аббревиатуры и имена собственные могут совпадать
намеренно.
