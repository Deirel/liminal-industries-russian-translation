# Liminal Industries: Russian Translation

An unofficial Russian translation for:

* [Liminal Industries](https://www.curseforge.com/minecraft/modpacks/liminal-industries) **1.19.3 (Original)**
* [Liminal Industries - Rescripted](https://www.curseforge.com/minecraft/modpacks/liminal-industries-rescripted) **1.19.3 - 7 (AE2 fix)**

The mod translates:

* FTB Quests titles, subtitles, and descriptions
* Item and block names from the modpack
* In-game guidebooks

Missing translations have been added throughout the modpack. Books created with **Patchouli** have been translated, reviewed, and validated. Issues with clipped text, broken recipe pages, and links to missing recipes have also been fixed.

Other guidebooks are translated, but their translations have not yet been fully reviewed.

The translations are applied **client-side and in memory only**. The mod does not replace or modify FTB Quests configuration files, create backups, or change quest/books/achievements progress. Removing the mod restores the original text.

User-provided Russian translations take priority. If the source text of a supported quest or book changes, the mod does not overwrite it with an outdated translation.

## Compatibility

Supported modpacks:

* Liminal Industries **1.19.3 (Original)** with FTB Quests **2001.4.13**
* Liminal Industries - Rescripted **1.19.3 - 7 (AE2 fix)** with FTB Quests **2001.4.22**

Shared requirements:

* Minecraft **1.20.1**
* Forge **47.4.13**

Each release is built for one exact modpack edition and quest book. Use the JAR that matches the installed modpack edition. Unsupported or changed quest and book content retains its original text.

***

## Installation

1. Download the JAR that matches the installed modpack edition.
2. Place the mod JAR in the client profile's `mods` folder.
3. Select Russian in Minecraft's language settings.

~=×=~

The mod is not required on dedicated servers. Each player who wants the translation installs it on their own client.

No separate resource pack or manually installed quest configuration is required.
