# Глоссарий перевода Liminal Industries

Канонический список терминов находится в `QUEST_GLOSSARY.tsv`. Этот документ
хранит только правила, которые нельзя выразить двухколоночной таблицей.

## Источники

Для названия игрового объекта используй источники в таком порядке:

1. точный item/block ID из манифеста версии;
2. итоговый перевод из version-specific payload;
3. штатный `ru_ru` точной версии Minecraft или мода;
4. утверждённое редакторское решение из `QUEST_GLOSSARY.tsv`.

Нельзя выбирать перевод только по совпавшей английской строке: одинаковые
названия из разных модов могут иметь разные русские UI-имена.

## Классы терминов

- `UI_RU` — точное имя, которое игрок видит в интерфейсе;
- `KEEP_EN` — бренды, собственные имена и технические обозначения;
- `LORE` — естественный и единообразный перевод обычной прозы.

Секции и пары в `QUEST_GLOSSARY.tsv` являются источником истины для всех трёх
классов.

## Неизменяемый текст

Не переводи:

- названия модов и брендов;
- `namespace:id`, команды, NBT, имена файлов, координаты и адреса;
- разметку и плейсхолдеры: `&o`, `&l`, `&6`, `§6`, `{image:...}`, `%s`, `%d`;
- единицы и сокращения: `FE`, `RF`, `AE`, `FE/t`, `RF/t`, `NBT`, `P2P`;
- названия клавиш `Shift`, `Ctrl`, `Alt`;
- явно обозначенные имена людей, книг и музыкальных композиций.

Сочетания действий можно писать как `Shift + ПКМ` и `Shift + ЛКМ`.

## Добавление термина

1. Найди запись в манифесте и проверь точный ID объекта.
2. Проверь version-specific payload и штатные языковые ресурсы.
3. Для UI используй точное отображаемое имя, включая регистр и дефисы.
4. Добавь одну пару в подходящую секцию `QUEST_GLOSSARY.tsv`.
5. Проверь термин поиском по всем переводимым строкам версии.

Markdown-таблицы с копией терминов не создаются: один термин редактируется
только в TSV.

## Стиль

- Пиши коротко и естественно для игрового интерфейса.
- Используй официальный перевод Minecraft: `редстоун`, `скалк`, `Незер`,
  `Энд`, `эндерняк`.
- Не переноси английскую капитализацию каждого слова.
- Используй одно русское имя для одного UI-объекта во всей версии.
- Не исправляй очевидную ошибку исходника буквально: используй фактическое имя
  существующего объекта из секции исправлений TSV.

## Контроль

Перед утверждением перевода:

1. проверь единообразие терминов по всей версии;
2. проверь сохранность разметки и технических токенов;
3. проверь, что `KEEP_EN` не переведены и не склоняются;
4. запусти `scripts/approve_version_translations.py`;
5. пересобери payload и выполни runtime-аудит отдельно.
